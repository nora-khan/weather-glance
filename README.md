# Terminal Weather CLI ⛅🌡️

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![CI](https://github.com/nora-khan/weather-glance/actions/workflows/ci.yml/badge.svg)](https://github.com/nora-khan/weather-glance/actions)

Real-time, ultra-fast weather reports and atmospheric conditions right in your command line.

## Highlights
- 🌦️ **ANSI Metrics**: Real temperature, wind speed, and humidity.
- ⚡ **Instant Execution**: Lightweight single-file tool with no external dependencies.

## Usage
```bash
python weather.py Tokyo
python weather.py London
```
